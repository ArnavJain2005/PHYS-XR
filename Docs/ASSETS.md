# PHYS-XR: The Presence — Asset register

Every asset the game ships, where it comes from and under what terms. The Technical
Spec (section C, M0, M10) asks for this register before anything third-party ships.

## What ships today: original, generated in code

All art and audio in the build is created at runtime by code in this repository. Nothing
is imported, downloaded or traced from third-party material, so the whole game is covered
by the repository's own licence (`LICENSE`).

| Kind | Where | What it is |
|---|---|---|
| Surface textures | `Assets/PHYSXR/Game/Art/ProceduralTextures.cs` | Floorboards, damask wallpaper, wainscot, plaster, tiles, rugs, wood, metal, paper, siding, roof, ground, fabric, portraits/landscapes, rain streak, soft blob, menu backdrop. Value-noise and pattern functions; normal maps derived by Sobel filter. |
| Materials | `Assets/PHYSXR/Game/Art/HouseMaterials.cs` | URP Lit materials built from those textures. |
| Material templates | `Assets/PHYSXR/Resources/PHYSXR/Mat_*.mat`, `FlatNormal.png` | Five template materials and a 4×4 flat normal map, generated by `PHYS-XR > Art > Create Material Templates`. They exist only so player builds keep the shader variants used at runtime. |
| Geometry | `Assets/PHYSXR/Game/Art/MeshKit.cs`, `Game/Level/BlackthornGreybox*.cs` | Boxes, cylinders and quads with metre-scaled UVs; the house, furniture and exterior are composed from them. |
| The Hollow | `Assets/PHYSXR/Ghost/Presentation/HollowVisual.cs` | Procedural figure (primitives plus a generated shroud mesh), procedural animation, particle wisps. |
| Sound | `Assets/PHYSXR/Game/Audio/ProceduralAudio.cs` | 39 cues synthesised from oscillators, filtered noise and envelopes: ambience, storm, thunder, menu music, footsteps, clock, creaks, UI, objective sounds, power surge/hum, ghost voice and attack sounds, lantern, heartbeat, stings, radio static. |
| Fonts | Operating-system fonts at runtime (`Font.CreateDynamicFontFromOSFont`: Georgia, Segoe UI, Consolas …), falling back to Unity's built-in `LegacyRuntime.ttf` | No font file is shipped. |

## Not imported (decision recorded)

The spec plans to bring across the Unity Learn "John Lemon's Haunted Jaunt" kit and a
Mixamo character from `E:\PHYS_XR`. They were **not** imported:

- Their licences are still marked "confirm" in the spec (Asset Store EULA for the kit;
  Adobe Mixamo terms for the character). Both allow use in a project but not
  redistribution of the source files, which committing them to this repository would be.
- The repository has no Git LFS rules yet (spec M0), and the kit is about 400 MB.
- The spec itself warns that the character reads as a zombie rather than an apparition.

`Assets/PHYSXR/Game/Audio/AudioOverrideLibrary.cs` leaves a door open: a local build can
map any `AudioCue` to a licensed clip by creating the asset
(`Create > PHYS-XR > Audio Override Library`) named `PHYSXR_AudioOverrides` in a
`Resources` folder outside version control. When absent, the procedural sound is used.

## Packages

No package was added. The game uses packages already in `Packages/manifest.json`:
URP 17.5.0 (post-processing volumes), Input System 1.20.0 (input and UI module), uGUI
2.5.0 (menus and HUD) and the built-in AI module (`UnityEngine.AI` NavMesh building).
`com.unity.ai.navigation` is installed but not used by the game code.
